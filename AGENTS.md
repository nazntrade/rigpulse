# Постоянные инструкции пользователя

- После завершения и проверки изменений RigPanel (RigPulse) самостоятельно создавать коммит и пушить его в GitHub. Постоянное разрешение пользователя от 25.10.2026; повторное подтверждение для обычного коммита и push не требуется.
- Не включать в коммит секреты, пользовательские данные и посторонние изменения. Не использовать force push. Если push заблокирован, сообщить причину.
- Сборки всех приложений выполнять локально. Облачные сборки GitHub Actions отключены по просьбе пользователя от 29.10.2026; не включать их автоматически. Проверки, коммиты и push остаются обязательными. Готовые локальные установщики при необходимости загружать в релиз без повторной облачной сборки.
